# 领星数字SKU清理助手

当前版本：v1.1.2

Windows 桌面程序，用于领星 OMS「平台订单 → 待处理」中的重复清理流程。

## 固定删除条件

产品行只有同时满足以下条件才会被移除：

1. 平台 SKU 只由 ASCII 数字 `0-9` 组成；
2. SKU 为空或 `-`；
3. 产品名称为空或 `-`；
4. 可用库存为空或 `-`；
5. 删除后订单仍至少保留一行产品。

程序只精确点击目标产品行的「移除」、确认框的「确定/确认」以及唯一的「保存」。不会点击审核、取消或删除订单。

## 使用

1. 双击桌面的「领星数字SKU清理助手」。程序会自动启动检查。
2. 第一次使用时，在程序打开的专用 Chrome 窗口登录领星；以后会保留该会话。
3. 保持 Chrome 窗口打开，程序会自动扫描、逐单处理并复核。
4. 完成后程序会弹窗反馈，并把 JSON 报告保存到 `%LOCALAPPDATA%\\LingxingNumericSkuCleaner\\reports`。

如需只看命中结果，可在程序启动后的界面勾选「仅扫描」并重新点击开始。开发或验收时也可使用命令行参数 `--scan-only` 启动。

交付到桌面后：

- 双击 `领星数字SKU清理助手.exe`：自动正式执行；
- 双击 `领星数字SKU清理助手（仅扫描）`：只检查和反馈，不修改订单。

## 中断与异常

- 点击「停止」后，程序会在当前安全检查点停止。
- 保存状态不确定时不会重复点击；订单会记为异常并写入报告。
- 页面结构变化、候选数超过 200 或产品表外字段变化时会停止保存。
- 程序会自动选择足以容纳全部待处理订单的分页数量；待处理订单超过 2000 笔时停止，避免漏扫。
- 连续 3 笔出现完全相同的异常时会提前安全停止，避免整批订单重复失败。
